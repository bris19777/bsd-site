# אתר BSD מחשבים

אתר סטטי (HTML/CSS/JS בלבד, בלי שרת ובלי מסד נתונים): קטלוג מחשבים ניידים, שירותים ויצירת קשר.
כל הזמנה נשלחת כהודעת וואטסאפ ל-054-457-8946, עם שם המחשב והמק"ט כבר כתובים.

## מבנה

| קובץ | תפקיד |
|---|---|
| `index.html` | מבנה הדף: כותרת, באנר, קטלוג, שירותים, יצירת קשר |
| `products.js` | **רשימת המוצרים והקטגוריות. כאן מעדכנים מוצרים** |
| `app.js` | בונה את הכרטיסים, הסינון וקישורי הוואטסאפ (מספר הוואטסאפ: `WA_NUMBER`) |
| `style.css` | עיצוב (צבעי המותג `#15396B` / `#2F7FE6`, גופן Rubik) |
| `images/` | תמונות המוצרים, בשם המק"ט |

## עדכון מוצר

ב-`products.js`, כל מוצר הוא שורה אחת:

```js
{ sku: "6092", cat: "basic", brand: "HP", name: "HP 250 G10", img: "images/6092.png",
  tagline: "...", specs: ["...", "..."] },
```

- **מחיר:** מוסיפים `price: "2490"`. בלי מחיר מוצג "מחיר לפי פנייה".
- **קטגוריות:** `basic` / `home` / `business` / `premium` / `gaming`.
- **תמונה:** שומרים ב-`images/` בשם המק"ט ומעדכנים את `img`.

## צפייה מקומית

```bash
cd bsd-site && python3 -m http.server 8765
```
ואז לפתוח http://localhost:8765 (פתיחה ישירה של index.html עובדת גם היא ברוב הדפדפנים).
