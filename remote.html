תמיכה מרחוק

פותרים את התקלה דרך האינטרנט, בלי להגיע ובלי לשלוח את המחשב. אתם רואים כל מה שקורה, וכל חיבור דורש את האישור שלכם.

BSD Support: כלי בדיקה ותמיכה, בלי התקנה

כלי קטן שפיתחנו ב-BSD מחשבים. קובץ אחד שמפעילים בלחיצה כפולה, בלי התקנה, ויש בו שלושה דברים:

  • 🖥
    תמיכה מרחוק חד-פעמית. לוחצים "התחל תמיכה מרחוק", ועל המסך מופיעים מספר מזהה וסיסמה שמוסרים לטכנאי בטלפון. החיבור פעיל רק בזמן התמיכה, ונסגר כשלוחצים "סיים תמיכה" או סוגרים את התוכנה.
  • 🔍
    בדיקת המחשב. מצב הכוננים, בריאות הסוללה, זיכרון, טמפרטורות, ותקלות מ-30 הימים האחרונים (כולל מסכים כחולים וכיבויים לא תקינים). את הדוח אפשר לשמור כתמונה, PDF או טקסט ולשלוח לנו בוואטסאפ.
  • ⚡
    בדיקת מהירות. מהירות האינטרנט וביצועי המעבד, כדי לראות אם המחשב או הקו איטיים.

איך משתמשים?

  1. מורידים בכפתור "הורדת כלי הבדיקה" שבכרטיס ההורדות, ומפעילים את הקובץ. אם מופיע חלון כחול של Windows, ראו כאן מה לעשות.
  2. לתמיכה מרחוק: לוחצים "התחל תמיכה מרחוק" ומוסרים לנו את המזהה והסיסמה.
  3. לבדיקת המחשב: עוברים ללשונית הבדיקה. לבדיקה מלאה Windows יבקש אישור (לוחצים "כן"), ובסוף לוחצים "ייצוא דוח" ושולחים לנו.

גרסה 3.7.0 · ל-Windows 10 / 11 · כ-25MB. התמיכה מרחוק מבוססת על RustDesk, תוכנה חופשית ברישיון AGPL-3.0 (קוד המקור).

מה זו התוכנה?

תוכנת התמיכה של BSD מחשבים מבוססת על MeshCentral, מערכת תמיכה מרחוק בקוד פתוח (בדומה ל-TeamViewer או AnyDesk). ההבדל: היא רצה על שרת פרטי של BSD מחשבים, ולא דרך חברה חיצונית, והחיבור מוצפן מקצה לקצה.

  • ✓
    רק באישור שלכם. לפני כל חיבור קופץ חלון בקשת אישור במחשב, ובלי אישור אין חיבור.
  • ✓
    גלוי לאורך כל החיבור. בזמן התמיכה מוצג סרגל שמראה שיש חיבור, ואפשר לנתק בלחיצה.
  • ✓
    שקוף. התוכנה מופיעה בשם "BSD Computers Support" ברשימת השירותים של Windows, ואפשר לבקש להסיר אותה בכל עת.

איך מתחילים?

  1. מתקשרים או שולחים וואטסאפ ומספרים מה התקלה.
  2. מורידים את התוכנה בכפתור "הורדת תוכנת התמיכה" שבכרטיס ההורדות.
  3. מפעילים את הקובץ. אם מופיע חלון כחול של Windows, ראו כאן מה לעשות. בחלון ההרשאות של Windows לוחצים "כן".
  4. ממלאים את השם ולוחצים "התקנה" בחלון ההתקנה של BSD מחשבים (ראו תמונה).
  5. מודיעים לנו שסיימתם. נתחבר אחרי שתאשרו את בקשת החיבור במסך.

מופיע חלון כחול "Windows הגן על המחשב שלך"?

זה רגיל ולא מסוכן: Windows מציג את ההודעה הזו על תוכנות שהוא עוד לא מכיר. היא יכולה להופיע בשני הקבצים שבעמוד, גם בתוכנת התמיכה וגם בכלי BSD Support, וממשיכים באותה דרך, בשני שלבים:

ב-Windows באנגלית הכפתורים נקראים More info ואז Run anyway. מתקשים? כתבו לנו בוואטסאפ ונעזור.

התוכנה לא עובדת? יש דרך נוספת

אם לא הצלחתם להתקין את תוכנת התמיכה, או שהחיבור לא עובד, אפשר לקבל תמיכה דרך פורטל השירות של BSD מחשבים:

  1. נרשמים לפורטל השירות. ההרשמה קלה מאוד ולוקחת דקה.
  2. פותחים קריאת שירות ומתארים את התקלה. תקבלו קישור לתוכנת החיבור ScreenConnect.
  3. מתקינים: פותחים את הקישור, מאשרים את כל החלונות שקופצים, ובסוף מסמנים V ולוחצים Connect. בשלב הזה אתם נותנים את האישור שלכם לתמיכה מרחוק.
  4. זהו. אחרי ההתקנה נוכל להתחבר למחשב ולטפל בתקלה, בלי צורך בקוד.
