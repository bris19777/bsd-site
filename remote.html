תמיכה מרחוק

פותרים את התקלה דרך האינטרנט, בלי להגיע ובלי לשלוח את המחשב. אתם רואים כל מה שקורה, וכל חיבור דורש את האישור שלכם.

מה זו התוכנה?

תוכנת התמיכה של BSD מחשבים מבוססת על MeshCentral, מערכת תמיכה מרחוק בקוד פתוח (בדומה ל-TeamViewer או AnyDesk). ההבדל: היא רצה על שרת פרטי של BSD מחשבים, ולא דרך חברה חיצונית, והחיבור מוצפן מקצה לקצה.

  • ✓
    רק באישור שלכם. לפני כל חיבור קופץ חלון בקשת אישור במחשב, ובלי אישור אין חיבור.
  • ✓
    גלוי לאורך כל החיבור. בזמן התמיכה מוצג סרגל שמראה שיש חיבור, ואפשר לנתק בלחיצה.
  • ✓
    שקוף. התוכנה מופיעה בשם "BSD Computers Support" ברשימת השירותים של Windows, ואפשר לבקש להסיר אותה בכל עת.

איך מתחילים?

  1. מתקשרים או שולחים וואטסאפ ומספרים מה התקלה.
  2. מורידים את התוכנה בכפתור שבעמוד.
  3. מפעילים את הקובץ, מאשרים את חלון ההרשאות של Windows ולוחצים Install.
  4. מודיעים לנו שסיימתם. נתחבר אחרי שתאשרו את בקשת החיבור במסך.

התוכנה לא עובדת? יש דרך נוספת

אם לא הצלחתם להתקין את תוכנת התמיכה, או שהחיבור לא עובד, אפשר לקבל תמיכה דרך פורטל השירות של BSD מחשבים:

  1. נרשמים לפורטל השירות. ההרשמה קלה מאוד ולוקחת דקה.
  2. פותחים קריאת שירות ומתארים את התקלה. תקבלו קישור לתוכנת החיבור ScreenConnect.
  3. מתקינים: פותחים את הקישור, מאשרים את כל החלונות שקופצים, ובסוף מסמנים V ולוחצים Connect. בשלב הזה אתם נותנים את האישור שלכם לתמיכה מרחוק.
  4. זהו. אחרי ההתקנה נוכל להתחבר למחשב ולטפל בתקלה, בלי צורך בקוד.
